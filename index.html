영

김영광

2026-08-26 입사
굿투 부산지사Meta 광고·DB·보고홈페이지·카톡 비즈니스영상·이미지·문구 제작아우어·토큰플러스·제이앤베스트·리뷰트리 장부상위노출·AEO·블로그·보도 부

강점

  • 책임감이 강함
  • 승일·서연 매니저가 많이 의지함
  • 입사가 가장 빨라 업무 숙련도·이해도가 다른 매니저보다 높은 편
  • 장부 문제나 오류 검수 때는 보통 서연과 둘이 머리를 맞대고 오류를 찾음
  • 주변에 휘둘리지 않고, 무리 지어 다니지 않음
  • 원칙대로 움직이고 지시를 정확히 확인함
  • 메타·DB 주간 보고서와 소재 제언을 매주 제출
  • 퇴근 전 진행 사안을 번호 목록으로 보고

보완점

  • 유도리·센스가 부족함. 하나를 말하면 그 하나로만 쭉 가고, +α로 다르게 생각하는 힘이 약함
  • 실수가 생각보다 많음. 성향인지, 부산지사를 혼자 맡은 탓인지는 아직 판단이 어려움
  • 마감서는 팀장 검수로 걸러지지만 장부에는 실수가 남음
  • 업무가 몰리면 실수가 많아짐
  • 사람들과 소통이 원활하지 않음
  • 반복 질문이 생각보다 많음. 이해도가 다소 떨어지는 건지, 이해한 뒤 나중에 잊는 건지는 판단이 어려움
  • 업무를 기계적으로 하는 편

관리 포인트

  • 지시는 범위·예외까지 구체적으로 전달
  • 부산지사 물량이 팀의 절반. 11/5부터 서연이 보조하므로, 이후 실수가 줄어드는지 보면 원인을 가늠할 수 있음
  • 성향상 영업팀 전환은 맞지 않음

이서연

2026-09-14 입사
상위노출 · AEO·GEO블로그·웹사이트 포스팅홍보 기사 제작크몽·숨고인덕·제이솔·마케이드·제이투·와이즈·비상한·알앤알흐름 월 트래픽 정산이음·마케이드·퍼펙트·체험인·루메인·임소정·애드스테이션 장부

강점

  • 매우 꼼꼼하고 책임감이 강함. 실수가 적음
  • 장부 문제나 오류 검수 때는 보통 영광과 둘이 머리를 맞대고 오류를 찾음
  • 문제 해결 능력이 좋음. 방향만 잡아 주면 알아서 헤쳐 나감
  • 유도리·센스가 좋아 대화 내용과 기존 업무 자료만 보고도 곧잘 처리함
  • 하나를 말하면 다른 매니저보다 +α로 생각함. 나이가 있어서인지 생각이 어리지 않음
  • 소통이 원활함
  • 업체 응대에 적극적이고 잘함. 거래처 사장님과의 통화·응대도 무리 없이 소화
  • 질문이 정제됨. 단가·계산서·규정처럼 혼자 정하면 안 되는 것만 물음
  • 월초 장부 전수 대조와 미수금 요청 주도

보완점

  • 힘들어도 먼저 말하지 않음

관리 포인트

  • 업무 성향은 후임 팀장으로 가장 적합. 다만 본인이 맡을지는 성격상 직접 소통해 확인 필요
  • 성향상 영업팀 전환은 맞지 않음

  • 습득·이해가 빨라 질문이 많지 않음. 모르는 것은 교육 자료를 계속 찾아보며 익히는 편

5 송부[G2G부산지사] 정산 방, 부대표·김주란·박도윤 태그영광 · 서연
6 입금·세발이체확인증 확인 후 확정 금액으로 세금계산서 상신영광 · 서연 · 경지부
팀장이 하던 마감서 초안 검수 방식
  1. 영광·서연이 올린 마감서 초안을 장부 / 카카오톡 내역 / 다우오피스 내역 / 실제 플랫폼 진행 내역 / UI 전부와 대조
  2. 안 맞는 부분(오류)을 찾아 영광·서연에게 확인 요청
  3. 영광·서연이 확인 요청을 보고 마감서와 장부를 함께 수정
  4. 수정본 재확인 후 부산지사에 송부

4. 회송 (드라우프)

  • 조건: 로켓·그로스, 와우 전용 제외. 건별 택배 또는 화물 일괄
  • 견적 = 회송 실행가 + 제품비. 회송형 전용 URL로 등록
  • 경지부 사전 보고: 회사명 · 일정 · 건수 · 제품비. 리뷰엠엔씨 지결은 경지부

5. 트래픽 · 슬롯

  • 접수자가 접수부터 정산까지 끝까지 팔로업
  • 매입 장부 · 매출 장부 · 내부자 시트 · 외부자 시트 4곳 기입
  • 실행사마다 상품·단가가 달라 접수 전 어느 실행사인지 먼저 확인
  • 정산: 정산서 → 접수일·수량 대조 → 검산 → 지결(정산서 첨부). 단가 변경은 경지부 노티 + 시트 수정

6. 세금계산서 · 지출결의

  • 받는 돈 세발, 나가는 돈 지결. 외주 건은 둘 다, 지결 댓글에 세발 링크
  • 제목: YYMMDD 거래처 세금계산서 발행 / YYMMDD 거래처 품목 지출 건. 부산·흐름은 대행사-업체-영업담당자 필수
  • 결재선: 기안 → 운영지원팀 팀장 → 마케팅운영 파트장 → 경지부 → 대표님. 팀장 결재 후 경지부 화면에 노출
  • 상신 서류 임의 회수 금지. 대결 완료 건은 경지부 노티 후 재기안
  • 지결 금액 = 장부 금액. 개인 지급은 신분증·통장사본, 세전 기재
  • 발행 당일 노션 견적서·계산서 관리 업로드. 업체에는 견적서 페이지만 읽기 공유

7. 월초 장부 대조 · 미수금

  • 1~2일: 전 상품 매입·매출 장부를 접수 내역·시트·UI와 대조, 오류 0건 후 결과 노티
  • 직후 흐름 영업자별(본사·인천·송도·미추홀) 트래픽 월정산서 → 트래픽 정산방
  • 미수금 주내 수취. 경지부 월별 입출금 시트(C열 입금일, 보라색 = 세발 미상신) 수시 확인
